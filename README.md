# 艾斯卡普镇居民登记处

Escapement Resident Registry · 第一阶段 MVP。纯 HTML / CSS / 原生 JavaScript，无依赖、无账号、无后端、无昵称上传和本地存储。原目录中的其他游戏文件未修改。

## 本地启动

最简单：用现代浏览器直接打开本目录的 `index.html`。脚本使用顺序加载的普通脚本，无 ES Module / fetch 数据依赖，因此支持 file://。

推荐预览（已安装 Node.js 时，无须 npm install）：

```powershell
cd D:\EscapTownGame\escapement-registry
node scripts/serve.cjs
```

访问 http://127.0.0.1:4173 ，Ctrl+C 停止。端口占用时先停止旧服务。服务器仅监听本机。未来静态托管时上传 index.html、css、js、assets 即可，所有运行资源均为相对路径，无外部字体或 CDN。

## 更换美术与数据

把原创图片放到下列位置，刷新即可。文件名大小写请保持一致：

- `assets/images/牌背.png`
- `assets/images/ESP-HRT-2.png`
- `assets/images/ESP-SPD-2.png`
- `assets/images/ESP-CLR-2.png`
- `assets/images/ESP-DIA-2.png`

正式图片现已接入，保留原文件名和素材内容。缺失或加载失败时回退为简洁卡背、花色符号。卡背和纹章使用 `object-fit: contain` 完整显示，不拉伸、不裁切；卡背出现时占位装饰隐藏。首页右侧和翻牌卡背均使用正式卡背。镇徽使用 ESP-ORG-2.png，觉醒额外徽记使用 ESPT-2.png。可在 config.js 修改路径。

`js/data.js`：每区 occupations 为 8 条非正史演示职业。直接替换数组文字即可；可增删，但每池至少保留一条非空字符串。

`js/config.js`：districts[].weight 为相对区域权重，默认都是 1（各 25%）；awakeningProbability 默认 0.01（1%），可设 0 或 1 方便本地演出检查，检查后恢复。区域与觉醒分别判定，无第五区域。seedVersion 为算法版本盐，修改会整体重新分配结果。

`css/style.css`：四区颜色集中在 .roswyn / .vesper / .cloverden / .diamora；本地字体已通过 @font-face 接入，字体变量集中在文件末尾的首轮美术区块，详见 docs/visual-round-1.md。页面固定标签在 index.html，主要提示在 config.js。

## 确定性规则

昵称先 NFC 规范化并去除首尾空白，保留大小写和内部空格；按 Unicode 码点限 1–24 字符，拒绝控制及隐藏格式字符。不会把昵称插入 HTML，渲染使用 textContent。

种子为 JSON.stringify([seedVersion, nickname, UTC+8 日期]) 的 32 位 FNV-1a 哈希。使用 Mulberry32 整数伪随机序列，固定消费顺序为：区域 → 觉醒 → 职业 → 登记编号。无 Math.random。任何觉醒结果均保留所属区域。数据对象与渲染分离，未来可直接接入图片导出。

日期按设备当前时刻统一换算 UTC+8，与设备时区无关。登记提交时锁定当日日期；跨午夜已打开的卡片保留原档案，重新登记使用新日期。设备时钟错误仍会影响日期，离线无后端无法校时。

相同版本、相同配置及数据、相同规范化昵称、相同日期，跨设备得到相同结果。改职业池顺序 / 长度、区域权重、概率或版本可能改变对应结果，因此后续更新数据不承诺追溯旧档案。编号是确定性展示标识，不是保证全球唯一的身份凭证。

## 功能与交互

- 欢迎 → 输入校验 → 背面卡牌 → 3D 翻牌 → 完整档案 → 复制 / 重新登记。
- 普通状态显示“未觉醒”。稀有状态短暂异常提示后由“未觉醒”切换至“已觉醒 / ESCAPIST”，没有能力、武器、等级或称号。
- 键盘可完成流程：Tab 导航，Enter 提交，Enter / 空格翻牌；隐藏卡面使用 inert 和 aria-hidden，提示使用 live region。
- prefers-reduced-motion 禁用翻转、抖动与过渡；稀有状态仍有短暂文字核对提示。
- 桌面双栏、手机单栏；卡面随长昵称和职业文字增高，避免固定高度裁掉文字。
- 优先 Clipboard API，失败时尝试浏览器复制命令；仍失败会提供已选中的文本框供 Ctrl/Cmd+C 或长按复制。
